# Numerical Methods Lab

Python implementations of numerical methods covered in my VTU coursework.
Each script solves a sample problem and prints step-by-step iteration details.

## Methods Implemented

- **Bisection Method** (`bisection.py`) — finds a root of f(x) = x^3 - x - 2 by repeatedly halving the interval.
- **Newton-Raphson Method** (`newton_raphson.py`) — finds a root of the same function using derivative-based iteration.

## How to Run

Make sure Python is installed, then run any script directly:

```bash
python bisection.py
python newton_raphson.py
```

Each script prints the iteration table and the final approximate root.
